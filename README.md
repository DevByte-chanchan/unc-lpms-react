# Learning Plan Management System (LPMS)

## Project Description

The Learning Plan Management System (LPMS) is a proposed web-based solution designed for the undergraduate programs of the University of Nueva Caceres (UNC). The system aims to improve the current process of creating, managing, and approving syllabi and Table of Specifications (TOS) reports.

At present, faculty members manually prepare syllabi and TOS documents using multiple platforms such as Google Docs, Google Drive, and email. This process requires repetitive encoding, reformatting, and realignment of course materials, which consumes significant time and effort. Because of the absence of a centralized platform, outputs may vary in structure and quality, resulting in inconsistencies in assessment mapping, reference management, and documentation standards.

LPMS is proposed to address these challenges by providing a lightweight, secure, and user-friendly platform that streamlines academic document management. The system is designed to reduce administrative workload, maintain academic standards, support reliable assessment mapping, and generate exportable syllabi and TOS documents efficiently.

## Installation Guide

Follow these steps to set up the project locally:

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### 2. Navigate to the Project Folder

```bash
cd your-repository-name
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local server link provided by Vite, usually:

```bash
http://localhost:5173
```

## Branching Strategy

The project follows a collaborative Git branching workflow to maintain organized development and avoid conflicts in the main production branch.

### Main Branches
- `main` → Stable production-ready version
- `develop` → Primary integration branch for ongoing development

### Feature Branches
New features are developed in separate feature branches such as:

```bash
feature/user-authentication
feature/tos-management
feature/syllabus-module
```

Feature branches are merged into `develop` through Pull Requests (PRs) after review and testing.
