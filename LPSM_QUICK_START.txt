█ STEP 1: Backend Setup
  $ cd backend/lpsm
  $ npm install
  $ cp .env.example .env

█ STEP 2: Docker Database & Auto-Migrations
  $ cd ../..  # Back to project root
  $ docker-compose -f docker-compose.lpsm.yml up --build
  
  This will:
  ✓ Start MySQL (port 3308)
  ✓ Run migrations automatically
  ✓ Seed sample data (6 users, 3 learning plans)
  ✓ Start Express server (port 4002)

█ STEP 3: Frontend Setup
  $ npm install axios  # If needed
  $ npm run dev       # Vite dev server on http://localhost:5173

█ API ENDPOINTS

  POST   /api/learning-plans                    Create plan
  GET    /api/learning-plans                    List plans
  GET    /api/learning-plans/:id                Get plan details
  POST   /api/learning-plans/:id/documents      Upload document
  DELETE /api/learning-plans/:id/documents/:docId   Delete document
  POST   /api/learning-plans/:id/submit         Submit for review
  POST   /api/learning-plans/:id/review         Submit review
  POST   /api/learning-plans/:id/approve        Approve/return

  All requests require headers:
  X-User-Role: instructor | program_head | director_of_libraries | 
               industry_consultant | dean
  X-User-Id: <user_id>

█ TROUBLESHOOTING

  Backend not starting?
  → docker logs backend_lpsm
  → docker exec backend_lpsm npm run db:migrate

  Frontend can't reach backend?
  → Check API_BASE_URL in src/services/learningPlanService.js
  → Verify X-User-Role and X-User-Id headers are set
  → Check browser console for CORS errors

  Database connection failed?
  → docker ps | grep db_lpsm
  → docker logs db_lpsm

  Reset everything?
  → docker-compose -f docker-compose.lpsm.yml down -v
  → docker-compose -f docker-compose.lpsm.yml up --build

█ KEY FEATURES

  ✓ Role-based document uploads (Program Head & Director of Libraries)
  ✓ Parallel review workflow (IC & Director review simultaneously)
  ✓ Sequential approval (Program Head → Dean)
  ✓ Dean comment relay (to Program Head only, never to Instructor)
  ✓ LocalStorage persistence + Backend database
  ✓ Workflow step visualization (StatusTracker component)
  ✓ File upload validation by role and document type
  ✓ SASS module styling (responsive, no inline styles)
